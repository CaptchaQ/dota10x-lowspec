# 5_pak66_builder — VPK-overrides (рекомендуемый способ)

## Зачем это нужно

Если ты уже запускал `2_particle_killer/kill_particles.bat` и в игре **ничего не поменялось** — это значит **loose-file overrides** (отдельные файлы в `game/dota/particles/...`) у тебя не сработали. Так бывает на свежих установках Dota 2 — Valve местами выкидывает loose-file механизм.

Эта папка решает проблему. Вместо разложенных файлов мы **собираем настоящий VPK-архив** (`pak66_dir.vpk`) и кладём его рядом с `pak01_dir.vpk`. Source 2 **гарантированно** мондтит все `pak*_dir.vpk` файлы по номеру, и `pak66` побеждает `pak01` на одинаковых путях. Этот механизм используется в популярном [dota2-minify](https://github.com/egezenn/dota2-minify) (тот же подход, тот же номер).

## Использование (1 команда)

```
kill_particles_pak66.bat total
```

Что произойдёт:
1. Скрипт прочитает твой `pak01_dir.vpk` и найдёт все 80,731 партикл.
2. Извлечёт байты Valve'овской пустой партиклы (`null.vpcf_c`, 851 байт).
3. Соберёт **`pak66_dir.vpk`** (~70 МБ) с этими байтами под путями всех партиклов.
4. Положит его в `<dota>/game/dota/pak66_dir.vpk` (рядом с `pak01_dir.vpk`).
5. Перезапусти Dota — партиклы исчезли.

При первом запуске спросит подтверждение (Y/N). Покажет dry-run сначала.

## Откат

```
uninstall_pak66.bat
```
Или вручную: удали `pak66_dir.vpk` в `<dota>/game/dota/`. Всё, ванилла.

## Пресеты

Те же что и в `2_particle_killer/`:

| `safe` | ~19,700 | косметика, idle, portrait |
| `aggressive` | ~30,400 | + дым/трейлы каста |
| `nuclear` | ~39,400 | всё кроме projectile-ов |
| `total` | ~80,700 | **абсолютно всё** |

## Зависимости

- Python 3.7+
- Пакет `vpk` от ValvePython (если не установлен, .bat сам поставит через pip)
- Полная установка Dota 2 (нужны `pak01_NNN.vpk` чанки чтобы прочитать null-стаб)

## Сравнение с loose-file подходом (`2_particle_killer/`)

| | `2_particle_killer/` (loose files) | `5_pak66_builder/` (pak66 VPK) |
|---|---|---|
| Файлов записывается | 80,731 отдельных файлов | 1 файл (pak66_dir.vpk, ~70 МБ) |
| Где лежит | `game/dota/particles/...` | `game/dota/pak66_dir.vpk` |
| Гарантированно работает | нет (зависит от установки) | **да** (тот же механизм что в minify) |
| Откат | uninstall.bat (сносит 80,731 файл) | удалить 1 файл |
| Steam validate | может сломать | не трогает |

**Используй pak66.** Loose-file вариант оставлен как простая альтернатива и для совместимости.

## Сравнение с dota2-minify

[dota2-minify](https://github.com/egezenn/dota2-minify) — известная утилита (148★, 28 релизов) с готовым GUI и набором модов:
- Dark Terrain (тёмный террейн)
- Remove Foilage (удаляет растительность)
- Remove River (удаляет реку)
- Remove Weather Effects (удаляет погоду)
- Remove Hero Renders, Showcases, Sprays и т.д.
- Misc Optimization (общая оптимизация)

Она работает на том же `pak66_dir.vpk` подходе. **Если хочешь больше чем просто партиклы** (тёмная карта, удалить деревья, упростить интерфейс) — поставь minify, у них есть GUI и проверенные сообществом моды.

Мой тулкит сфокусирован специфически на 10-окнах: убить максимум партиклов, чтобы CPU/GPU не плавились. Они не пересекаются — можно ставить и то и другое (оба пишут в разные имена pak: minify в pak65/66/67, я могу в pak68 чтобы не конфликтовать через `--pak-number 68`).
